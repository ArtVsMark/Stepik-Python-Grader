# Архив документации

**Здесь всё, что описывает прошлое:** история разработки, ротированный
CHANGELOG, разовые аудиты с приложениями, завершённые планы и отработанные
постановки для Claude. `docs/README.md` ссылается на этот индекс одной строкой —
человеку, который пришёл разобраться, как работает грейдер, сюда заходить не
нужно.

**Граница простая:** в активных `docs/*` — только «как это работает сейчас».
Как только документ начинает рассказывать «что и в каком порядке мы сделали», он
переезжает сюда. Что сделано в каждом релизе — в
[`../../CHANGELOG.md`](../../CHANGELOG.md); что открыто — в `gh issue list`.
