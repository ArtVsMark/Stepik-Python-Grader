# Ролевые срезы аудита 2026-07-15

Приложения к сводке [`../audit-2026-07-15.md`](../audit-2026-07-15.md): полные
разборы восьми ролей, из которых сводка собрана. Каждый файл начинается с
методики — что именно читалось и запускалось, чтобы находка была проверяемой, а
не оценочной.

**Аудит отработан.** Заведённые по нему эпики закрыты, находки либо исправлены,
либо осознанно отклонены — детали в сводке. Файлы сохранены как история: они
показывают, какими были код и документация на момент v1.8.0+ и по какой методике
проверялись.

| Роль | Что смотрела | Файл |
|---|---|---|
| 🏛️ Архитектор | граф импортов AST-скриптом по всем модулям `src/`, сверка с задекларированным DAG, поиск циклов | [role-architect.md](role-architect.md) |
| 🔧 Разработчик | код вместо доков: runner/grader_core/tracer/web-слой, все маршруты HTTP API против `api.md`, репро-скрипты гонки при отмене | [role-developer.md](role-developer.md) |
| 🐍 Core Python Dev | идиоматичность ядра, типизация, работа с subprocess и путями | [role-corepython.md](role-corepython.md) |
| 🧪 Тестировщик | покрытие, слепые зоны, детерминизм прогонов | [role-qa.md](role-qa.md) |
| 🎨 Дизайнер | `index.html`/`app.css`/`app.js` целиком, контраст токен-пар по WCAG для обеих тем | [role-designer.md](role-designer.md) |
| 📊 Продуктовый аналитик | путь новичка руками на `.venv`, весь funnel по коду, подсчёт карточек глоссария | [role-product.md](role-product.md) |
| 📝 Документационный аналитик | достоверность документации против кода, дубли и дрейф | [role-docs.md](role-docs.md) |
| 🚀 Визионер | направление продукта, чего не хватает для следующего шага | [role-visionary.md](role-visionary.md) |

> Почему у подкаталога появился свой индекс: без него восемь файлов были
> сиротами — ни одной входящей ссылки, и CI-проверка полноты индексов их не
> видела (она смотрит каталоги, у которых есть `README.md`). Теперь они
> навигируемы, а новый ролевой срез нельзя положить сюда молча.
