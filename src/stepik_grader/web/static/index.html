            История прогонов

            Прогоны сохраняются локально в .grader_history.db для раздела «Подучить» — хранится sha256 решения, не исходный код. Отключить: перезапуск сервера с --no-history.

            Согласие на AI-подсказку

            AI-подсказка отправит ваш код и ввод-вывод AI-провайдеру. Рекомендуется локальный провайдер (ollama) — данные не покинут вашу машину. Для несовершеннолетних требуется согласие представителя. Без согласия в сеть ничего не отправляется.

            🐍 С чего начать

            Локальная проверка решений Python — быстрый офлайн-цикл без ожидания Stepik.

            Режимы проверки
            • 📄Один файл — проверить одно решение по тест-кейсам.
            • 📁Папка — проверить все решения в папке разом.
            • ⚡Бенчмарк — сравнить скорость решений на повторных прогонах.
            • 🔬Микробенчмарк — точный замер одной функции (calls/run).
            🛡️

            Изоляция выключена по умолчанию. Грейдер рассчитан на ваш доверенный код. Изоляцию сети, файлов и ресурсов включают при запуске — галкой в лаунчере или флагом --sandbox. Из этого окна режим не переключить: сервер уже работает.

            ⬇️

            Скачивание задач — по желанию. Проверять решения можно без входа. Чтобы скачивать задачи со Stepik по URL, нужен OAuth (secrets.json).
