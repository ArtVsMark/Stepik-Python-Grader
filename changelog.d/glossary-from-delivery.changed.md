Карточки глоссария приезжают выгрузкой Glossary-Python: `scripts/import_glossary.py` раскладывает закреплённый выпуск (`glossary/data/_source.json`, сейчас v1.2.0, форма 6.0, 1710 карточек) после четырёх проверок — форма, схема выпуска, перенаправления, чтение без потерь. Карточка показывает, с какой версии Python есть имя, устарело ли оно, удалено или удаление только запланировано, и на каких ОС работает; пример — отдельными блоками; id слитой карточки открывает новую (#1573)
