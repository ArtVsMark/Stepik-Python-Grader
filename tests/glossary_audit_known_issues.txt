# 3.15; какое из двух записать в карточку — решается вместе с выходом 3.15,

#   bytearray.title — 3.15 не экранирует апостроф внутри двойных кавычек:
#     ждали bytearray(b"They\'Re Here"), получили bytearray(b"They'Re Here")
#   typing.TypeVarTuple — 3.15 печатает связанную переменную с тильдой:
#     ждали typing.Unpack[Ts], получили typing.Unpack[~Ts]
