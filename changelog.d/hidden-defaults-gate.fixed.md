Отпечаток рабочего дерева в `preflight.py` не замечал правок в файлах с не-ASCII именами: git отдаёт такое имя экранированным, путь не разрешался, и содержимое молча выпадало из отпечатка — то есть pre-push хук принимал состояние, которого гейт не проверял. Списки путей от git теперь читаются по NUL (`-z`) везде, где их потом используют, штамп называет охват числом, а новый гейт `scripts/check_hidden_defaults.py` разбором исходников держит оба умолчания: `-z` у списков путей и явную `encoding=` у текстового `subprocess` (43 места дописаны). Оба дефекта требуют совпадения платформы и данных, поэтому зелёная матрица про них не говорила ничего (#1417)
