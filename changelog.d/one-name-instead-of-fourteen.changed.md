Обязательная проверка защиты `main` теперь одна — `ci-complete`; четырнадцать прежних имён (джобы и ячейки матрицы) убраны из эталона. Имя ячейки несёт версию Python и флаг эксперимента, то есть меняется от ЧУЖОГО календаря: выход 3.14 из предрелиза добавил три строки, выход 3.15 добавил бы ещё три и убрал другие — и каждый такой сдвиг правился в двух местах сразу, в дереве и во внешней настройке репозитория, расходясь молча. Состав теперь выводит `ci_aggregate.expected_checks` из `ci.yml`, а переименование ячейки ловит прогон, а не память. Переход шёл по объявленному порядку: агрегатор появился → добавлен в обязательные, ничего не убирая → показал себя на живых PR (зелёный при красных предрелизных ячейках, красный при красной обязательной) → и только теперь имена убраны (#1420)
