Метки и связь с задачей на pull request стали проверяемым правилом: `check_pr_ready.py` отказывает мержить PR без `area/*`, без метки типа работы и без `Closes #N` — либо явного `Без issue: <причина>`. Отказ называет, чего именно не хватает. Метки конвейера под правило не подпадают, PR из форков не блокируются: внешний участник не обязан знать наши метки (#1329)
