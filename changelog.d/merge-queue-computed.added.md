Конвейер мержей: `gh_rest.py queue` печатает очередь из состояния API — кто голова, кто сколько ждёт, кто с кем делит файлы. Из `main` теперь обновляется **только голова очереди**, остальные стоят неподвижно: массовое обновление после каждого мержа гарантировало, что обновлённые PR устареют снова, и холостые прогоны росли как N(N−1)/2 против N (при шести PR — 21 против 12). Очередь вычисляется, а не хранится: ни меток, ни табло, которым разъезжаться между окнами. `check_pr_ready.py` отвечает «ждать» зелёному PR, если перед ним кто-то есть, и называет кто (#PR)
