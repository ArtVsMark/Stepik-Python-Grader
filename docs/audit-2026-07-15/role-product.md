### Сильные стороны

- **Дифференциация против «просто запустить в PyCharm» реальна:** вердикты AC/WA/TLE/RE per-case, построчный diff при WA, автоскачивание тест-кейсов из Stepik (ZIP/HTML-таблица/GitHub), честный бенчмарк двух решений, error card с подсказкой по исключению в момент боли (`reporter.py:423-427`), `--watch`, pytest-плагин, интеграция VS Code/PyCharm. PyCharm ничего из этого «из коробки» не даёт.
- **Учебная петля v1.8.0 спроектирована правильно:** SQLite-история (#344) → таксономия падений `failure_kind` с отделением format-WA от смысловых (`core/insights.py:49-94`) → затухание по прогонам, а не календарю → карточки «Подучить» в CLI (меню 5, `--insights`) и web (#348). Ключевой инсайт прошлого аудита («инсайт умирает при закрытии вкладки») архитектурно закрыт.
- **Грейдинг работает без OAuth** — документация честно это говорит, «Первый пример за 2 минуты» (grader-workflow.md) снижает порог.
- **Философия приватности выдержана:** никакой сетевой телеметрии, вся аналитика локальная и для самого ученика.
- **Web как поверхность для новичка** («кому консоль — барьер»): 7 разделов, error/action cards, песочница с трейсером, downloader по URL.

### Находки

1. **[CRITICAL] Канонический первый запуск падает трейсбеком.** `stepik-grader --mode 1 --file task.py` (относительный путь — ровно как в «Первом примере за 2 минуты», grader-workflow.md шаг 3) после diff падает `ValueError: 'task.py' and '/abs/dir' have different anchors`. Причина: `cli/commands.py:289` (`base = solution.resolve().parent` — абсолютный) + `core/reporter.py:218` (`path.relative_to(base_dir, walk_up=True)` на неразрешённом `solution`). Регрессия v1.8.0: коммит aa62a0d (#354) заменил `os.path.relpath` (терпит смешанные пути) на `relative_to`. Воспроизведено на v1.8.0-теге; абсолютный путь работает, `--mode 2 --dir .` работает. Тот же паттерн `_rel(solution.parent, cwd)` в `commands.py:263` уронит и `--history` с относительным путём. Первые 5 минут сломаны в главной документированной команде.
2. **[HIGH] Петля удержания «Подучить» мертва по умолчанию.** `record_history=False` (`config.py:62`); в интерактивном меню включить невозможно — `cli/interactive.py:206-209` читает только `[tool.stepik-grader]` из pyproject.toml, которого у pipx-ученика в папке задач нет; web-прогоны вообще не пишут ни историю, ни статистику — `web/viewmodels.py:431,553` зовёт `run_tests`/`run_benchmark` напрямую, минуя слой записи `cli/commands.py` (grep: ноль вызовов `history.record_run`/`stats.record_run` в `web/`). Итог: пункт меню «5. Подучить» и раздел web «Подучить» для пользователя по умолчанию — вечный empty state «прогоните с --history», причём в web этот совет невыполним внутри web. Флагманская retention-фича выключена для 100% дефолтной аудитории.
3. **[HIGH] OAuth — стена ровно перед главным дифференциатором.** Чтобы скачать тесты (ядро ценности), новичок должен: создать OAuth-приложение на stepik.org, вручную собрать `secrets.json` (шаблон `secrets.json.example` есть только в git-клоне — pipx-пользователю недоступен), и если файла нет — `downloader_config.normalize_config_paths():116-124` лишь повторно спрашивает «путь к secrets.json», после чего `main()` умирает сырой «❌ Ошибка подготовки данных: FileNotFoundError» (`downloader.py:340-345`). В продукте нет ни wizard'а создания secrets (в коде ни одного упоминания `oauth2/applications` — только в доках), ни ссылки на инструкцию в тексте ошибки.
4. **[MEDIUM] Метрики успеха: два хранилища, и оба слепы к воронке.** `.grader_stats.jsonl` пишет только `mode/os/verdicts/total_time` (`stats.py:91-98`) — не может ответить ни на «время до первого зелёного», ни на «повторяю ли я ошибку» (нет task_key/попыток). Это умеет `history.db`, т.е. хранилища дублируются (новые «двойники» — тема прошлого аудита воспроизводится). Не собирается вообще: конверсия downloader→первая проверка, попытки-до-AC per task, источник прогона web/cli (`runs.source` есть в схеме, но web не пишет). Комментарий `stats.py:42-48` («web-слой пишет статистику из web/runs.py») не соответствует коду.
5. **[MEDIUM] Глоссарий по умолчанию разбавлен черновиками более чем наполовину.** `glossary_search(status=None)` возвращает все 1388 карточек, дефолт фронта `status: ""` (`app.js:46`); 787 автодрафтов с пустым `summary` и внутренними именами вроде `_frozen_importlib._DeadlockError` (drafts.json) видны ученику списком с бейджем «draft». Для целевой аудитории («Поколение Python: для начинающих») это шум, подрывающий доверие к справочнику. Наполнение — эпик #363, но дефолтная фильтрация ready-only и исключение приватных (`_*`) имён из выдачи — отдельная быстрая победа.
6. **[MEDIUM] Режимы: 1/2/5 — ядро, 3/4 — перегруз для ученика; цикл итерации разорван.** Два бенчмарка с разной семантикой (Memory RSS vs «Py-heap», 4+6 профилей нагрузки — `interactive.py:51-65`) — ценность для ученика минимальна, а меню усложняют; кандидат на объединение в один «Сравнить решения». Меню — one-shot (`_interactive_menu`: «показать один раз … и завершить», `interactive.py:196`): каждый цикл «поправил код → проверил» требует перезапуска и повторного ввода пути — хуже, чем кнопка Run в PyCharm, если не знать про `--watch` (обнаруживаемость флага из меню нулевая).
7. **[LOW] Дрейф числа карточек:** «581 карточка» в `README.md:44`, `docs/web-current.md:269`, `web/glossary_adapter.py:86` против фактических 601 ready (после волны B1, PR #388/#390).
8. **[LOW] Латентная бесконечная рекурсия** в fallback-ветке `_print` (`downloader_config.py:41-46`: без rich функция вызывает саму себя вместо `print`) — сработает у пользователя с урезанной установкой ровно в момент, когда rich недоступен.

### Рекомендации (по приоритету)

1. **Hotfix-релиз** относительного пути в режиме 1 (находка 1): `solution = solution.resolve()` на входе `_run_mode_1` либо возврат толерантного relpath; регресс-тест с относительным путём из cwd. Это блокер первых 5 минут.
2. **Оживить петлю «Подучить»:** писать историю из web (source="web" уже предусмотрен схемой), дать тумблер истории в меню/web-настройках; рассмотреть default-on (данные локальные, PII нет — философия не нарушается) с `--no-history`. После FAIL-прогона печатать однострочный nudge про `--insights`.
3. **Снять OAuth-стену:** интерактивная генерация `secrets.json` (промпты client_id/secret + печать ссылки на `stepik.org/oauth2/applications` и требуемых полей приложения) вместо цикла «файл не найден».
4. **Глоссарий: ready-only по умолчанию**, черновики — за явным фильтром; приватные `_*`-имена не показывать ученику.
5. **Метрика TTFG** («попыток/времени до первого AC» по task_key) в `--insights`/«Мой прогресс» — главный измеримый показатель ценности продукта для самого ученика; заодно решить судьбу дублирующего `.grader_stats.jsonl` (свести к view поверх history.db).
6. Меню: после завершения режима предлагать «Enter — повторить, m — меню» (дешёвая замена полного цикла), упомянуть `--watch` в подвале результата.

**Оценка направления: 6.5/10.** Дифференциация и архитектура учебной петли — сильные; но релиз v1.8.0 сломал документированный первый запуск, retention-фича выключена для всей дефолтной аудитории, а самый ценный шаг воронки (скачивание тестов) заперт за самым тяжёлым шагом (ручной OAuth).
