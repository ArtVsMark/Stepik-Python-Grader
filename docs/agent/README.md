им — [`../use/`](../use/README.md) и [`../dev/`](../dev/README.md).

Главный агентский контракт — [`../../CLAUDE.md`](../../CLAUDE.md) (инварианты,
запреты, стиль, команды). Здесь лежит то, что в него не влезает по объёму.

## Про очередь работ коротко

Заполняется после крупного аудита и только связанным пластом задач — когда есть
жёсткие блокеры или «делать вместе, иначе фикс недоказуем». Плоский список
независимых задач живёт в GitHub Issues.

Волна разобрана — запись **удаляется**, а не помечается «✅ выполнена». Пометки о
сделанном превращают доску очереди в мёртвый журнал: прежняя редакция так выросла
до 336 строк отчётов и начала врать про статусы. Отчёты о сделанном —
[`../../CHANGELOG.md`](../../CHANGELOG.md), исторические разборы —
[`../archive/`](../archive/README.md).

Полные правила ведения — [`../../CLAUDE.md § Открытая работа`](../../CLAUDE.md).
