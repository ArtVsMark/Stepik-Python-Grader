Обход веток не открывает PR заново на голове, чей PR уже закрыли не смержив: закрытие — вынесенное решение, а `ahead_by` его увидеть не может (squash не делает коммиты ветки предками `main`, и она навсегда остаётся «впереди»); смерженный PR запретом не является, а снимается он удалением ветки (#1497)
