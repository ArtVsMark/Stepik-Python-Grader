Две инструкции для внешнего читателя перестали быть невыполнимыми. Установка: на Debian/Ubuntu 24.04 и Fedora системный Python помечен externally-managed (PEP 668), и рекомендованный первый шаг `python -m pip install --user pipx` отказывает — теперь рядом стоит рабочий путь через менеджер системы (`apt`/`dnf`) и объяснено, почему обходить запрет `--break-system-packages` не нужно. Канал жалоб в `CODE_OF_CONDUCT.md`: обещание конфиденциальности отправляло «через личное сообщение на GitHub», которых у GitHub нет, а английская врезка двумя абзацами ниже звала в публичные Issues и Discussions — то есть туда, где жалоба видна тому, на кого жалуются; обе половины теперь называют один рабочий адрес (#961)
