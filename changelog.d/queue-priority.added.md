Очередь мержей исполняет приоритет, а не только готовность: `blocker`, `P0`, `priority-high` и далее по шкале — метку ставит владелец на задачу, а PR наследует её через `Closes #N`. Красный `main` очередь **замораживает**: двигается только PR с меткой `blocker`, потому что проверки остальных всё равно прошли бы на сломанной базе. Вывод `queue` называет обоснование порядка, иначе он выглядит произвольным (#1326)
