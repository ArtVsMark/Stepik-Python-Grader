Правило агентских веток записано в `CLAUDE.md`: ветвиться в `agent/<slug>` — только такую ветку подхватывает `agent-pr.yml`, открывая PR от имени владельца и включая авто-мерж. Из облачной сессии PR смержить нечем (GraphQL режется прокси целиком, REST-мерж в защищённую ветку запрещён), поэтому имя ветки — не удобство, а единственный способ довести работу до `main` без участия человека; для уже открытых PR остаётся метка `merge-when-green` (#1302, #1303)
