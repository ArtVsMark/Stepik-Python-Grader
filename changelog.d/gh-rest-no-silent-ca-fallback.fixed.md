REST-транспорт конвейера (`scripts/gh_rest.py`) больше не ослабляет проверку сертификата сам: строгая проверка формы CA (`VERIFY_X509_STRICT`, включён по умолчанию с Python 3.13) даёт отказ с названной причиной и лечением, а ослабление включается только явной `GH_REST_RELAXED_CA=1` — с предупреждением в stderr на каждый запрос и разделом в SECURITY.md (#1250, #1264)
