## 🎨 Дизайнер

**Методика.** Прочитаны целиком `web/static/index.html` (422 стр.), `app.css` (663), `app.js` (2468), `core/reporter.py` (446), `cli/interactive.py` (263), локали `core/locales/ru.json|en.json`; сверка с прошлым аудитом (`docs/audit-2026-07.md § 6`) — что закрыто в v1.8.0. Контраст токен-пар пересчитан скриптом (WCAG relative luminance) для обеих тем; вендоренный CodeMirror-бандл проверен grep'ом на экспорт тёмного HighlightStyle.

**Сильные стороны (не повторять как находки).** Прошлый аудит в значительной мере отработан: разделы «Правила (PEP)»/«Подучить» реализованы ровно по предложенным wireframe (статусы 🔥/🌤/✅, бейджи sidebar, deep-link `#/rules/<code>`); блок «Стиль» в CLI жёлтый, не красный (`reporter.py:385`). Системный уровень высокий: полноценные дизайн-токены (`app.css:49-160`), три темы (system/light/dark) с синхронизацией тумблера и «Настроек», вендоренные шрифты (офлайн + приватность), `prefers-reduced-motion`, `:focus-visible`, aria-live анонс результата и `role="progressbar"` (#298), нейтральный CANCELLED (#296), empty states с позитивным тоном, командная палитра Ctrl+K, dirty-индикатор редактора (#297), пошаговый трейс-плеер с aria-label'ами и стрелочной навигацией.

### Находки

**D-1. Ядро сценария «Разбор» недоступно с клавиатуры — только мышь.** `high` · WCAG 2.1.1.
Все ключевые интерактивы результата — `<td class="file-cell" data-toggle>` (раскрытие кейсов, `app.js:1648,1661-1662`), `<tr class="case-row">` (открытие «Разбора», `app.js:1684-1689`) и `<li>` списков решений/глоссария/правил (`app.js:688-690, 1992-1994, 2157-2159`) — вешают только `click`, без `tabindex`/роли/`keydown`. Клавиатурный пользователь после прогона (фокус даже заботливо переводится на панель, `app.js:842-843`) не может открыть ни один тест-кейс. Табы «Таблица/Разбор» — `role="tab"` без `aria-controls`/`tabpanel`/стрелочной навигации (`index.html:150-153`).

**D-2. Тёмная тема проваливает AA на ключевых элементах.** `high` · пересчитано:
- белый текст главной кнопки «▶ Запустить» на `--color-primary #4f98a3` — **3.31:1** (`app.css:117,308`);
- `badge-error` `#d163a7` на `#4c3d46` — **2.93:1** (плашки WA/FAIL, `app.css:129-130,323`);
- активный пункт sidebar / mode-btn: primary на primary-highlight — **3.56:1** (`app.css:252,405`);
- `--color-text-muted` (hints, подписи форм, kpi-label — мелкий текст) — **4.12:1** dark / **4.03:1** light, ниже AA 4.5:1.
Issue #298 поднял только warning-цвет; остальной набор dark-токенов не проверялся.

**D-3. Код в редакторе нечитаем в тёмной теме.** `high`. `makeEditor()` подключает `defaultHighlightStyle` (`app.js:478`) — светлую палитру CodeMirror: keyword `#708` на `#161614` — **1.85:1**, string `#a11` — 2.41, comment 2.74, definition 2.60. Бандл `vendor/codemirror-bundle@6.mjs` не экспортирует ни `oneDark`, ни `HighlightStyle`/`tags` (проверено по export-списку) — тёмную подсветку сейчас нечем собрать без пересборки бандла. Касается редакторов режима 1, песочницы и трейс-плеера.

**D-4. `--color-text-faint` (1.82:1 light / 2.44:1 dark) используется для контента, а не только плейсхолдеров.** `medium`. `.section-heading` («Функции в коде»), `.term-card-kind`, `.palette .kbd`, `.trace-lineno` (`app.css:448-452,569,500,601-604`) — реальные подписи ниже даже порога 3:1 для крупного текста. Плейсхолдерам можно, заголовкам секций — нет.

**D-5. CLI: жёсткий `Console(width=200)` и таблица без единиц времени.** `medium`. `reporter.py:46` фиксирует ширину 200 — на терминале 80–120 колонок rich не ужимает таблицу (думает, что места хватает), и bench-таблица из 10 колонок рвётся жёсткими переносами терминала посреди рамок. Заголовки «Total time»/«Avg time» режимов 1/2 (`reporter.py:127-131,209-211`) не говорят, что это секунды, — тогда как режимы 3/4 имеют автоединицы `fmt_time` (s/ms/µs/ns) и подписанную «Memory, MB». Плюс расхождение семантики цвета: TLE в CLI красный (`reporter.py:186`), в web — жёлтый `badge-warning` (`app.js:85`).

**D-6. Скрытые аффордансы интерактивного меню CLI.** `medium`. (а) Пустой ввод пути открывает нативный tkinter-диалог (`interactive.py:159-170`) — отличная фича, но prompt «Введите путь к файлу решения: » (`ru.json:enter_solution_path`) о ней молчит: новичок не узнает никогда. (б) Меню одноразовое — выбрал режим, прогон, выход (`interactive.py:196`): для сессии «правлю решение → перепроверяю» приходится перезапускать процесс (в web это решено кнопкой). (в) В меню 0–5 нет пункта про веб-интерфейс — `--serve` открывается только тем, кто прочитал доки; главная витрина проекта не обнаруживаема из его же главного экрана. (г) `_ask_number` молча подставляет дефолт на нечисловой ввод (`interactive.py:68-73`) — без сообщения.

**D-7. Палитра команд и поиск: пробелы a11y и устаревший реестр.** `medium`. `role="dialog" aria-modal="true"` без focus trap — Tab уводит фокус под оверлей (`app.js:247-263`); `#palette-input`, `#glossary-search`, `#rules-search` — без label/aria-label, только placeholder (`index.html:410,226,285`). Команда `switch_section` циклит `["check","downloader","glossary","sandbox"]` (`app.js:181-185`) — разделы rules/insights/settings, добавленные в #348/#364, из цикла выпали (тот же класс бага, что чинил #317). Skip-link (`index.html:10`) навсегда скрыт: у `.sr-only` нет `:focus`-раскрытия (`app.css:192,487-490`) — зрячий клавиатурный пользователь его не видит.

**D-8. Жаргон и мелкие несоответствия тона.** `low`. Кнопки режимов «Режим 1…4» + «Bench»/«Microbench» (`index.html:50-53`) — номер-first нумерация из CLI и непереведённый жаргон; студенту нужны задачи («Один файл / Папка / Скорость / Микротесты»), номер — вторичен. Tooltip disabled-кнопки «Скоро — issue #55» (`index.html:111`) утекает внутренним трекером в пользовательский UI и недоступен с клавиатуры. Переключатель «English» в Настройках меняет только сообщения сервера/глоссарий — весь хром остаётся русским (честно описано в hint, но ожидание нарушено). KPI «OK» всегда `variant:"up"` — зелёный «0%» при нуле прошедших (`app.js:1639`).

### Рекомендации (с wireframe)

1. **Клавиатура в результатах (D-1):** строку файла делать `<button aria-expanded>` внутри `<td>`; case-row — `tabindex="0" role="button"` + Enter/Space; li-списки — заменить на `<a href="#/glossary/<id>">` (роутер уже есть). Паттерн табов — по APG (aria-controls + стрелки).
2. **Тёмные токены (D-2/D-4):** поднять dark `--color-primary` до ~`#66aab5` (или тёмный текст на кнопке), `badge-error` dark → текст `#e698c6`+, `--color-text-muted` до ~`#8f8d8a`; завести отдельный `--color-text-placeholder`, а `text-faint` в контенте заменить на muted. Прогнать все пары скриптом в CI (мини-чек по токенам).
3. **Редактор (D-3):** пересобрать бандл с экспортом `HighlightStyle`/`tags` и собрать подсветку на дизайн-токенах (`tags.keyword → var(--color-purple)` …) — одна палитра на обе темы автоматически.
4. **Режимы (D-8):** `[ Один файл ] [ Папка ] [ Бенчмарк ] [ Микробенчмарк ]` с подписью-номером мелким (`Режим 1`) — сохраняет маппинг на CLI, убирает жаргон с первой строки.
5. **CLI (D-5/D-6):** `Console()` без width (авто); заголовки «Total time, s»; prompt «Введите путь (Enter — открыть диалог выбора): »; после прогона возвращаться в меню до выбора «0»; пункт «6. Открыть веб-интерфейс (--serve)».
