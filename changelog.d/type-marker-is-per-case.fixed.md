Файл `N.type` снова означает «кейс N», а не весь набор: одного `1.type` хватало, чтобы все кейсы уехали в function-режим, и верное stdin-решение получало `RE` на каждом — при том что оставшийся файл мог просто пережить прошлую задачу в той же папке. Глобальный вывод теперь делается, только когда маркер есть у каждого кейса формата 1 либо кейсов формата 1 нет вовсе (форматы 2 и 3 `.type` не читают) (#996)
