Ссылка на несуществующую карточку глоссария или правила говорит «не найдено» вместо тихого отказа: раньше при 404 на экране оставалась ранее открытая карточка, и студент, пришедший из своей ошибки за объяснением, читал чужое объяснение как ответ. Заодно починены сами прямые ссылки на карточки с кириллическими id («остаток», «срез») — сервер брал путь из запроса закодированным и не находил их никогда, то есть без этой правки новое состояние уверенно врало бы о существующей карточке (#969)
