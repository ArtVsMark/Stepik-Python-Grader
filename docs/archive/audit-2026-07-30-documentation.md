## Что оказалось в порядке

Это важно для интерпретации остальных находок: формальная гигиена документации
была в норме, разъехалось именно **содержание**.

- **0 битых ссылок** из 683 локальных — ни одного мёртвого пути или якоря.
- **13 дублированных строк** (≥60 символов, в ≥2 файлах) на 16 758 строк —
  буквального копипаста практически нет, правило «канонические источники»
  соблюдалось.
- Все четыре CI-гейта документации были **зелёными**. Именно это и есть корень:
  гейты проверяли форму (ссылки, бюджет README, полноту одного индекса), а не
  содержание.

## F1. Расхождение чисел между документами — ✅ закрыто (#757)

Одно и то же число жило в трёх-четырёх версиях сразу.

| Факт | Реальность на момент аудита | Что было написано |
|---|---|---|
| Тестов | 2168 (`pytest tests/`) | README «2100+», `versions.md` «1700+» ×2, `history.md` «1600+» |
| Карточек глоссария | 1349 (бейдж = факт) | CLAUDE.md «1300+», CHECKPOINT «~1333», `web-current.md` «~1349» |

**Решение:** числа изъяты из прозы, живой источник — бейджи README. В
`versions.md` добавлено правило: значения фиксируются в таблице только для
закрытых релизов.

## F4. Археология вместо объяснения — ✅ закрыто (#759)

**2906 упоминаний `#issue`** в документации. Худшие случаи:

| Файл | Строк | Ссылок на issue |
|---|---|---|
| `dev/architecture.md` | 242 | **164** |
| `dev/project-structure.md` | 132 | **77** |
| `dev/web-current.md` | 950 | 110 |

Колонка «что делает модуль» в `architecture.md` превратилась в лог решений:
*«…реэкспортирован им как `cli._build_arg_parser` и т.д. (issue #119, Stage 1
эпика #117)»*. Читателю нужен контракт модуля, а не номер спринта, в котором он
появился.

**Решение:** хвосты сняты — в объясняющих документах их ноль. Остаток по
репозиторию (2045) весь в законных зонах: `CHANGELOG.md`, `archive/`, `audit/`,
ADR и требования-идентификаторы в `dev/design/`. Правило «где номер уместен, где
нет» описано таблицей в [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md) и
защищено машинно — `check_issue_tail_policy` держит объясняющие документы на
нуле, зонам `design/`/`agent/` задаёт бюджет.

438 строк, из которых уникален по сути только § Версионирование (116 строк —
канон схемы «тег = MINOR+1», на него ссылаются CLAUDE.md, ADR-0005 и полдюжины

**Решение:** § Версионирование вынесен в
[`../dev/versioning.md`](../dev/versioning.md), CONTRIBUTING сжат до онбординга
со ссылками вместо пересказов.

## F8. Гибриды и сироты — ✅ закрыто (#761)

`web-current.md` на 950 строк смешивал два читателя: обзор разделов интерфейса
для пользователя и контракты данных с user journeys для разработчика. Восемь
`archive/audit-2026-07-15/role-*.md` оставались сиротами — ни одной входящей
ссылки, и CI-проверка полноты индексов их не видела, потому что смотрит только
каталоги со своим `README.md`.

**Решение:** документ разделён по читателю на
[`../use/web-interface.md`](../use/web-interface.md) (419 строк: разделы,
загрузчик, глоссарий, раскладка, доступность) и
[`../dev/web-contracts.md`](../dev/web-contracts.md) (472 строки: journeys,
error/action cards, реестр команд, устройство фронтенда, формы данных). Ролевым
срезам дан свой индекс — теперь они навигируемы, и гейт следит за их полнотой.

`dev/design/` по решению владельца остаётся как есть: дизайн-документы читаются
как контракты, пока серверный трек не начат.
