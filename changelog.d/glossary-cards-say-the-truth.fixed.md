Пятнадцать карточек глоссария перестали учить неверному. `any` обещал `False` там, где Python печатает `True`; `id` учил, что `id([]) == id([])` даёт `False` — на деле `True`, потому что первый список успевает освободиться и адрес переиспользуется; `signal.ItimerError.__name__` оказался `itimer_error`, а не `ItimerError`; `math.isclose(1.0, 1.0000001)` объявлялся истинным, хотя `rel_tol` по умолчанию 1e-09; двенадцать карточек `math` округляли ответ и прятали погрешность double вместо того, чтобы её показать. Заодно `math.fsum` больше не иллюстрирует различие, которого с Python 3.12 нет: встроенная `sum()` для float считает компенсированной суммой (issue #919, находки `ADD-3-02`…`ADD-3-05`).
