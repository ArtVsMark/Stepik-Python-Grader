Окно лаунчера показывает логическую версию отдельной строкой — `Версия 1.10.253`, у релиза `Версия 1.11`: то же число, что в бейдже README. Считается один раз при сборке (`scripts/generate_build_info.py` → `_build_info.json` в пакете) и только читается на старте — без git и подпроцессов, которых в установленном через pipx пакете нет, а на macOS + 3.14 они подвисают на десятки секунд. Полная PEP 440-версия с хешем остаётся в заголовке окна: по ней сборка сопоставляется с коммитом (#PR)
