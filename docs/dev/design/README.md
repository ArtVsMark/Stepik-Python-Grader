# Дизайн без реализации

**Здесь описано то, чего в коде нет.** Дизайн-документы доведены до контрактов и
смержены, но соответствующий код не написан и живого issue на билд не существует
— направление держит единственный roadmap-issue
[#59](https://github.com/ArtVsMark/Stepik-Python-Grader/issues/59).

**Как это читать:** как контракт, который уже согласован. Если берёшься за
реализацию — опирайся на эти документы, а не проектируй заново. Если считаешь
решение неверным — сначала правь дизайн и ADR, потом код.

**Чего здесь не искать:** того, что работает сегодня. Реализованное — в
[`../README.md`](../README.md): локальная песочница `--sandbox`, протокол
`Runner`, контракт результата и текущий HTTP API уже в коде.
