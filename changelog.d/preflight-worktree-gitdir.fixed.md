`python scripts/preflight.py` в рабочем дереве `git worktree` больше не падает `FileExistsError` до первой проверки: штамп, блокировка и логи кладутся в служебный каталог, который называет сам git (`rev-parse --git-dir`), а не в собранный `<корень>/.git` — в worktree это ФАЙЛ `gitdir: ...`, и `mkdir(exist_ok=True)` на нём падает, потому что `exist_ok` прощает существующий каталог, а не файл. Штамп и логи остались у каждого дерева свои, а блокировка прогона стала общей на репозиторий: два параллельных `pytest` роняют тесты с subprocess одинаково — из основного каталога запущен второй прогон или из соседнего worktree. Без git — прежнее поведение (#1251)
